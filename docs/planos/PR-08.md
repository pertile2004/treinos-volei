## 1. Objetivo
RF-05: listar exercícios, filtrar por fundamento e nível, buscar sem diferenciar maiúsculas e acentos e ver o detalhe com descrição, foco, padrões e vídeo. Somente leitura; a gestão (POST/PUT/DELETE) é dos PR-09 a PR-11.

## 2. Contrato (/api/v1) — como ficou

### 2.1 GET /exercicios
- Quem pode: qualquer usuário logado (`auth:sanctum` + ExercicioPolicy::viewAny). Sem sessão: 401. Não há limitador de taxa (o 429 fica para o PR-05).
- Entrada (query string, tudo opcional; valor vazio é ignorado), validada em ListarExerciciosRequest:

| Campo | Regras |
|-------|--------|
| fundamento | Rule::enum(Fundamento) |
| nivel | Rule::enum(Nivel) |
| busca | string, máx. 100; aparada; casa só com `nome` |
| page | inteiro ≥ 1 (inválido dá 422) |
| por_pagina | inteiro 1–50; padrão 15 |

- Comportamento: filtros por E; busca `lower(unaccent(nome)) LIKE lower(unaccent(?))` por binding, com `%`, `_` e `\` escapados (unaccent antes de lower, porque `lower()` com collation C não minusculiza "Ç"); excluídos ficam fora (RN-07); ordem nome, id; `paginate()->withQueryString()`.
- Resposta 200: paginador padrão do Laravel (`data`, `links` first/last/prev/next e `meta` com current_page, from, last_page, links, path, per_page, to, total). Item (ExercicioResumoResource):
```json
{ "id": 12, "nome": "Recepção em manchete contra a parede", "foco": "Plataforma firme e direção da bola",
  "fundamento": "recepcao", "fundamento_rotulo": "Recepção", "nivel": "iniciante", "nivel_rotulo": "Iniciante",
  "series_padrao": 3, "repeticoes_padrao": 15, "duracao_segundos_padrao": null, "descanso_segundos": 45,
  "tem_video": false, "imagem_url": "/ilustracoes/recepcao.svg" }
```
  `imagem_url` nunca é null: sem imagem própria vem `/ilustracoes/<fundamento>.svg`. A lista não traz `descricao` nem `video_url`.
- Erros: 401 · 422 (`errors` por campo, pt-BR).

### 2.2 GET /exercicios/{id}
- Quem pode: qualquer logado (ExercicioPolicy::view). `{id}` restrito a numérico.
- 200 (ExercicioResource): os campos do item, menos `tem_video`, mais `descricao` e `video_url` (URL gravada ou null).
- Erros: 401 · 404 (inexistente, excluído logicamente ou id não numérico). `criado_por`, `deleted_at` e timestamps não são expostos.

Nenhuma rota existente foi alterada. Cabeçalho novo em todas as respostas: `Content-Security-Policy: frame-src 'self' https://www.youtube-nocookie.com` (ADR-026).

## 3. Modelo e dados
- Migrations (semente d14ef3c): `criar_extensao_unaccent` (`Schema::ensureExtensionExists('unaccent')`) e `criar_tabela_exercicios` (colunas do MODELO-DE-DADOS; `video_url` e `imagem_url` varchar(255) null; índice composto (fundamento, nivel) e índice de `criado_por`; SoftDeletes). Sem índice de expressão para a busca (cerca de 40 linhas).
- Model `Exercicio`: `#[Table('exercicios')]`, `#[Fillable]`, SoftDeletes, casts para os enums, `criador()`; neste PR ganhou `ilustracaoDoFundamento(Fundamento)` e `imagemUrlOuPadrao()`.
- Seeder `ExercicioSeeder`: lê backend/database/seeders/dados/exercicios.json (42 exercícios, 6 por fundamento, todos com foco, padrões e descanso; `video_url` todos null, porque nenhum vídeo foi conferido); `Exercicio::withTrashed()->updateOrCreate(['nome'])`, `criado_por` null, `imagem_url` = ilustração do fundamento. Chamado pelo DatabaseSeeder.
- Policy: ExercicioPolicy com viewAny e view (ADR-027); o PR-09 acrescenta a escrita.

## 4. Regras garantidas no servidor
- RN-07: escopo padrão do SoftDeletes na lista e no detalhe (404 para excluído).
- RN-11: as duas rotas exigem sessão; a biblioteca é comum a todos os papéis.
- RN-13: nenhum botão sem função; a aba "Meus Treinos" só informa (EstadoVazio) até o PR-13.
- Vídeo: `video_url` nunca inventada; o front só monta o player se a URL for do YouTube (watch, youtu.be, embed, shorts, v, nocookie; id de 11 caracteres), em `https://www.youtube-nocookie.com/embed/<id>`, sem autoplay.
- Paginação: 15 por padrão e teto 50 no FormRequest (422 acima).

## 7. Telas e decisões de interface
- Biblioteca: abas "Treinos Prontos" (lista) e "Meus Treinos" (EstadoVazio informativo); chips "Todos" + fundamentos e grupo "Nível" com "Todos" + 3 níveis, rótulos de GET /referencias; busca com rótulo visível "Buscar exercício" e debounce de 300 ms; filtros na query string (fundamento, nivel, busca, pagina; filtro novo apaga `pagina`); cartão inteiro é link para o detalhe, com ilustração decorativa, etiquetas e padrões resumidos ("3 × 15", "4 × 30 s"); paginação "Anterior"/"Próxima" com "Página X de Y"; região `aria-live` com o total; esqueleto `aria-busy`; erro com request_id e "Tentar de novo"; vazio com "Limpar filtros" só quando há filtro.
- Detalhe: Cabecalho com voltar para /biblioteca e o nome como h1 ("Detalhe do exercício" enquanto carrega, no erro e no 404); etiquetas; player só com URL válida, senão a ilustração; "Descrição", "Foco" e "Padrões" (dl; descanso 0 vira "Sem descanso"); 404 com "Voltar para a Biblioteca".
- Ilustração: SVG aplicado como `mask-image` com a cor do token (um `<img>` não herda `currentColor`), sempre `aria-hidden`.
- Sem login nesta frente: nenhuma RotaProtegida; 401 e 403 mostram a mensagem da API. A proteção entra na entrega com o PR-05.
