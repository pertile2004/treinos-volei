### src/lib/http.js (exporta `http`, `definirNavegacao(funcao)`, `buscarCookieCsrf()`)
- `axios.create({ baseURL: '/api/v1', withCredentials: true, withXSRFToken: true, headers: { Accept: 'application/json' } })`.
- Requisição: header `X-Request-Id` = `crypto.randomUUID()`, novo a cada requisição (inclusive na repetição).
- Resposta 419: `GET /sanctum/csrf-cookie` (axios puro, withCredentials) e repete a mesma requisição UMA vez (marca `config.csrfRepetido`); segundo 419 rejeita.
- Resposta 401: se o caminho atual não for `/entrar`, navega para `/entrar?voltar=<encodeURIComponent(pathname + search)>` e rejeita o erro. Navegação padrão `window.location.assign`; main.jsx troca por `roteador.navigate(destino, { replace: true })`.

- `requestId`: `response.data.request_id` → header `x-request-id` da resposta → `X-Request-Id` enviado → null.
