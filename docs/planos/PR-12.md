# Plano — PR-12 · Treinos: cadastro

Branch: `feature/pr-12-treinos-cadastro` (base: main + sementes de dados dos cards 04, 08 e 12 e o acesso à API de exercícios no front). Pacotes de trabalho: **backend**, **frontend**, **fechamento**.

## 1. Objetivo
RF-07 (criar): o usuário logado monta um treino com nome, descrição, nível, visibilidade e de 1 a 30 exercícios da biblioteca distribuídos nas 4 etapas, em ordem, e salva. A gravação é atômica (treinos + treino_itens) e o servidor calcula `duracao_estimada_minutos`. Listar, detalhar, alterar e excluir ficam para os PR-13, 14 e 15.

## 2. Contrato

### POST /api/v1/treinos (rota nova, nome `treinos.criar`)
- Quem pode: qualquer usuário logado (`auth:sanctum`; `TreinoPolicy::create` devolve true). O que muda por papel é a visibilidade aceita (RN-06).
- Sem rate limit próprio: o projeto ainda não tem limitador registrado (pendência do PR-01, fica para a frente de autenticação).

Campos de entrada (JSON):

| Campo | Regras |
|---|---|
| nome | obrigatório, texto, máx. 120 |
| descricao | opcional (null), texto, máx. 2000 |
| nivel | obrigatório, enum Nivel (iniciante, intermediario, avancado) |
| visibilidade | obrigatório, restrito pelo papel: jogador só `privado`; treinador `privado` ou `atletas`; admin `privado`, `atletas` ou `publico` |
| itens | obrigatório, array, mín. 1, máx. 30 |
| itens.*.exercicio_id | obrigatório, inteiro, existe em `exercicios` com `deleted_at` nulo |
| itens.*.etapa | obrigatório, enum Etapa (aquecimento, tecnica, especifico, volta_a_calma) |
| itens.*.ordem | obrigatório, inteiro 1–32767; o par (etapa, ordem) não se repete no pedido (conferido em `after()`, vira 422 em vez de erro do banco) |
| itens.*.series | obrigatório, inteiro 1–10 |
| itens.*.repeticoes | nullable, inteiro 1–100; obrigatório quando `duracao_segundos` está ausente |
| itens.*.duracao_segundos | nullable, inteiro 10–3600; obrigatório quando `repeticoes` está ausente |
| itens.*.descanso_segundos | obrigatório, inteiro 0–600 |

- Repetições e duração juntas são aceitas (a duração vale no cálculo).
- `autor_id` e `duracao_estimada_minutos` nunca vêm do cliente: são ignorados se vierem.
- Mensagens em pt-BR. Fixas neste PR: visibilidade fora do papel ou inexistente → "A visibilidade escolhida não está disponível para o seu papel." (`errors.visibilidade`); exercício inexistente ou excluído → "O exercício escolhido não existe ou foi removido da biblioteca." (`errors["itens.N.exercicio_id"]`); sem repetições nem duração → "Informe repetições ou duração em cada exercício." (em `itens.N.repeticoes` e `itens.N.duracao_segundos`); (etapa, ordem) repetido → "A ordem N já está em uso na etapa <Rótulo>." (`itens.N.ordem` do item repetido). Os demais usam o validador com os atributos descrição, nível, exercício, etapa, ordem, séries, repetições, duração e descanso (ex.: "O campo séries deve estar entre 1 e 10.").

Resposta 201 — `{ "data": {...} }`:
```json
{
  "data": {
    "id": 12, "nome": "Recepção e saque — terça", "descricao": "Foco em passe para o levantador.",
    "nivel": "intermediario", "visibilidade": "privado", "duracao_estimada_minutos": 7,
    "autor": { "id": 3, "nome": "Lucas" },
    "itens": [
      { "id": 40, "etapa": "aquecimento", "ordem": 1, "series": 2, "repeticoes": null, "duracao_segundos": 60, "descanso_segundos": 30,
        "exercicio": { "id": 7, "nome": "Deslocamento lateral", "fundamento": "preparo_fisico", "removido": false } },
      { "id": 41, "etapa": "tecnica", "ordem": 1, "series": 3, "repeticoes": 10, "duracao_segundos": null, "descanso_segundos": 45,
        "exercicio": { "id": 15, "nome": "Recepção em manchete", "fundamento": "recepcao", "removido": false } }
    ],
    "criado_em": "2026-11-06T14:00:00Z"
  }
}
```
- Chaves exatamente essas (não há `atualizado_em`). `criado_em` em ISO 8601 UTC sem fração. Itens sempre ordenados por etapa (na ordem do enum) e `ordem`, independentemente da ordem de envio. `exercicio.removido` é `deleted_at` não nulo (sustenta o selo "removido da biblioteca" do PR-13).

Erros: 401 sem sessão · 419 CSRF expirado (o http.js repete uma vez) · 422 `{ message, errors, request_id }`. 403 e 404 não se aplicam.

Duração estimada (só no servidor, `TreinoService::estimarDuracaoMinutos`): por item, `series × (duracao_segundos, ou repeticoes × 3 s quando não há duração) + series × descanso_segundos`; soma em segundos, arredondada para cima em minutos, mínimo 1. Constante `TreinoService::SEGUNDOS_POR_REPETICAO = 3`.

Rotas consumidas sem mudança: GET /referencias (rótulos de nível, etapa, fundamento e visibilidade) e GET /exercicios (busca, fundamento, nivel, page — rota do PR-08, em outra frente; aqui só o acesso do front, vindo da semente).

## 3. Modelo e migrations (semente 3cfa98d, já no histórico)
- `treinos`: id · nome varchar(120) · descricao text null · nivel varchar(20) · visibilidade varchar(20) · autor_id → users (cascata) · duracao_estimada_minutos smallint · timestamps · deleted_at. Índice (autor_id, visibilidade).
- `treino_itens`: id · treino_id → treinos (cascata) · exercicio_id → exercicios (índice, sem cascata) · etapa varchar(20) · ordem smallint · series smallint · repeticoes smallint null · duracao_segundos int null · descanso_segundos smallint. Único (treino_id, etapa, ordem). CHECK `treino_itens_repeticoes_ou_duracao_check` (repeticoes ou duracao_segundos não nulo). Sem timestamps.
- Models `Treino` (#[Table('treinos')], SoftDeletes, casts Nivel e Visibilidade, `autor()`, `itens()`) e `TreinoItem` (#[Table('treino_itens', timestamps: false)], cast Etapa, `exercicio()` com `withTrashed()`); `User::treinos()`. Factories dos dois.
