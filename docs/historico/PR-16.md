## Decisões tomadas
- ADR-026: idempotência por id_cliente (201 primeiro envio, 200 reenvio), datas só com fuso, sem dependência nova (react-hook-form/zod seguem o ADR do PR-04 quando entrarem).
- ADR-027: throttle só nas rotas autenticadas; visibilidade do treino em SessaoService::podeVer até a TreinoPolicy do PR-13 existir; 404 em vez de 403 na SessaoPolicy.
- ADR-028: reducer puro com relógio por instantes; estado versionado no localStorage com o retrato do treino; aria-live só em troca de fase, "Descanso encerrado" e minuto.
- Nomes da lógica adiantada mantidos (maquinaDoTreino.js, armazenamentoDoTreino.js) em vez de maquina.js/armazenamento.js do rascunho; não há useCronometro separado (o tique está no useTreinoAtivo).
- Nome acessível dos botões igual ao texto visível ("+ Acerto", "+ Erro", WCAG 2.5.3), com aria-describedby para o total.
- Após a última série de um exercício que não é o último há descanso antes de "Próximo exercício" (comportamento da máquina adiantada).
- `series.*.numero` com max:999 (smallint); demais tetos conforme o contrato. Séries da resposta na ordem de envio (por id).
- Modal "outro treino em andamento": Esc/cancelar = Retomar; "Descartar e iniciar este" é a ação de perigo.
- CSRF: registrarSessao não busca o cookie antes do POST; conta com a repetição automática em 419 do http.js (segura pela idempotência).

## Como testar
1. `composer --working-dir=backend test -- tests/Feature/Sessoes` — 24 testes (transação e rollback, reenvio com o mesmo id_cliente, 404 para treino privado alheio, selo de exercício removido, 429).
2. `npm --prefix frontend run test -- --run src/funcionalidades/treino-ativo src/funcionalidades/sessoes src/paginas` — máquina com timers falsos, recarregar restaura, POST 500 → Tentar de novo com o mesmo id_cliente, axe por fase.
3. `npm run verificar`. Com a API no ar e um treino com itens (PR-12/13 mergeados): /treino → Iniciar treino → marcar acertos e erros → recarregar → Concluir série → Pular → … → Finalizar e salvar treino → volta a /treino com "Treino salvo.".
